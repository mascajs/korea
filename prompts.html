나라의 역사 시간여행

너는 중학생을 위한 웹 개발자이자 역사 교육 콘텐츠 기획자야.

[나라이름]의 역사를 처음 접하는 학생이 큰 흐름을 재미있게 이해할 수 있는 반응형 웹페이지를 만들어줘.

요구사항:
1. 제목은 “[나라이름] [   ] 여행”으로 해줘.
2. 역사를 [고대, 중세, 근현대]처럼 3~6개 시대로 나눠 가로 타임라인 버튼으로 보여줘. 그 나라의 특성에 맞춰 왕조의 변화나 중요한 역사적 전환점을 기준으로 시대를 나눠줘.
3. 시대 버튼을 누르면 아래 내용 카드가 바뀌게 해줘.
   - 시대와 연도
   - 핵심 사건을 설명하는 3~4문장
   - 당시 사람들의 생활
   - 대표 인물 또는 문화유산
   - 학생이 생각해 볼 질문 1개
4. 방문한 시대 버튼에는 체크 표시가 생기고, 모든 시대를 보면 축하 메시지를 보여줘.
5. 어려운 역사 용어는 중학생이 이해할 수 있는 말로 풀어줘.
6. 디자인은 그 나라 국기의 색을 사용한 현대적인 박물관 스타일로 해줘.
7. HTML, CSS, JavaScript가 한 Canvas 안에서 정상 작동하게 해줘.
8. 모바일 화면에서도 글과 버튼이 겹치지 않게 해줘.

역사적 사실은 단정적으로 지어내지 말고, 불확실한 내용은 “~로 알려져 있다”라고 표현해줘.
첫 번째 수정 미션“각 시대 설명에 대표 문화유산 이미지를 넣고 이미지 출처를 표시해줘.”

나라를 나타내는 상징 탐구

너는 중학생을 위한 인터랙티브 문화 웹 개발자야.

[국가 이름]을 나타내는 여러 상징을 탐구하는 교육용 웹페이지를 만들어줘.

먼저 [국기, 국가 문장, 국화, 상징 동물, 대표 색, 국가 표어] 중 이 나라에 실제로 존재하며 자료를 확인할 수 있는 상징 2~4개를 선택해줘. 모든 나라에 국화나 상징 동물이 있다고 가정하지 마.

요구사항:
1. 첫 화면에 국가 이름과 “상징에는 어떤 이야기가 담겨 있을까?”라는 탐구 질문을 보여줘.
2. 선택한 상징을 큰 카드로 보여주고, 카드를 누르면 상세 설명이 바뀌게 해줘.
3. 각 상징의 상세 설명에는 다음을 포함해줘.
   - 공식 명칭
   - 모양·색·문양의 의미
   - 언제부터 사용됐는지
   - 역사적 변화 또는 관련 이야기
   - 오늘날 어디에서 볼 수 있는지
4. 국기를 포함한다면 공식 비율과 색상, 문양을 정확히 표현해줘. 국기의 내부 요소가 의미를 가진 경우에만 클릭 영역을 만들어줘.
5. 국기 내부 요소가 단순한 나라라면 억지로 나누지 말고, 국기 전체와 다른 국가 상징을 각각 카드로 구성해줘.
6. 선택하지 않은 상태에는 테두리나 강조선이 보이지 않게 하고, 다시 누르면 선택이 해제되게 해줘.
7. 정부·대사관·박물관 등 신뢰할 수 있는 자료를 우선 확인하고, 페이지 아래에 출처 영역을 만들어줘.
8. 해당 국가의 상징색을 활용하되 국기 색을 임의로 바꾸거나 장식으로 왜곡하지 마.
9. 다른 나라의 문양이나 전통 요소를 섞지 말고, 확실하지 않은 상징은 제외해줘.
10. 모바일에서도 이미지 비율과 카드 배치가 유지되게 해줘.
첫 번째 수정 미션“상징과 의미를 연결하는 카드 맞추기 게임 3문제를 추가해줘.”

문화 비밀 보관소

너는 중학생을 위한 문화 체험 웹앱 기획자야.

[대한민국]의 [음악 / 전통의상 / 음식 / 문화유산 중 하나]를 깊이 있게 탐험하는 웹페이지를 만들어줘.

요구사항:
1. 주제를 4개의 세부 카드로 나눠줘.
   예: 음악이라면 [리듬, 악기, 대표 장르, 오늘의 변화]
2. 카드를 누르면 상세 설명 창이 열리게 해줘.
3. 각 상세 설명에는 다음을 포함해줘.
   - 쉬운 설명 3~4문장
   - 대표 사례 2개 이상
   - 과거와 현재의 연결
   - 잘못 알려지기 쉬운 점
   - 학생이 직접 해볼 체험 미션
4. 4개 카드를 모두 보면 별이나 배지를 받게 해줘.
5. 해당 문화의 특징이 느껴지는 색과 무늬를 사용하되 글자를 읽기 쉽게 해줘.
6. 한 국가를 하나의 고정된 이미지나 편견으로 표현하지 않게 해줘.
7. 외부 이미지를 사용한다면 저작권을 확인할 수 있도록 출처 영역을 만들어줘.
8. 모바일과 PC 모두에서 카드가 보기 좋게 배열되게 해줘.
첫 번째 수정 미션“세부 카드 하나에 소리를 재생하는 버튼이나 움직이는 시각 효과를 추가해줘.”

60초 문화 찾기 게임

너는 중학생이 1분 안에 즐길 수 있는 웹게임 개발자야.

[국가 이름]의 문화 그림을 이용한 “60초 문화 찾기” 게임을 만들어줘.

게임을 만들기 전에 먼저 Gemini 이미지 생성 기능으로 게임용 그림 한 장을 만들어줘.

그림 생성 조건:
- [국가 이름]의 서로 다른 문화 요소 5개를 한 장면 안에 자연스럽게 배치해줘.
- 문화 요소는 [역사적 건축물, 자연환경, 전통 악기, 음식, 현대 도시]처럼 서로 구분하기 쉬운 것으로 골라줘.
- 각 요소의 실제 형태와 해당 국가의 문화가 맞는지 확인해줘.
- 다른 나라의 건축·복식·문양을 섞지 마.
- 글자, 정답 표시, 로고와 워터마크는 넣지 마.
- 학생이 위치를 찾기 쉽도록 요소끼리 지나치게 겹치지 않게 해줘.
- 가로형 16:9 웹게임 배경 그림으로 만들어줘.

그림이 완성되면 그 이미지를 사용해 게임을 만들어줘.

요구사항:
1. 화면 한쪽에는 문화 요소 5개의 목록을 보여줘.
   예: [궁궐, 산, 전통 악기, 음식, 현대 도시]
2. 다른 쪽에는 문화 요소가 들어간 큰 그림을 보여줘.
3. 그림의 올바른 위치를 누르면 초록색 원과 체크 표시가 나타나게 해줘.
4. 목록에서도 찾은 항목에 취소선을 표시해줘.
5. 틀린 곳을 눌러도 감점하지 말고 “조금 더 살펴보세요”라고 알려줘.
6. 5개를 모두 찾으면 축하 효과와 걸린 시간을 보여줘.
7. “다시 하기” 버튼으로 처음부터 시작할 수 있게 해줘.
8. 게임은 1분 안에 끝날 만큼 쉽고, 클릭 영역은 모바일에서도 충분히 크게 만들어줘.
9. 그림의 문화 요소가 실제 국가의 것인지 다시 확인하고 다른 나라 요소를 섞지 않게 해줘.
10. 생성한 그림과 게임의 클릭 위치가 맞지 않으면, 그림을 기준으로 클릭 영역의 위치와 크기를 다시 조정해줘.
첫 번째 수정 미션“제한시간을 60초에서 40초로 바꾸고 힌트 버튼을 한 번만 사용할 수 있게 해줘.”

도전! 국가 문화 퀴즈

너는 중학생이 재미있게 학습할 수 있는 문화 퀴즈 웹게임 개발자야.

[국가 이름]의 역사와 문화를 알아보는 객관식 퀴즈 게임을 만들어줘.

요구사항:
1. 퀴즈는 총 5문제로 구성해줘.
2. 문제 분야가 한쪽에 치우치지 않도록 다음 내용을 골고루 포함해줘.
   - 역사 또는 중요한 사건
   - 음식
   - 음악·춤·축제
   - 전통의상 또는 생활문화
   - 문화유산·자연환경·국가 상징
3. 각 문제에는 보기 3개를 보여주고 정답은 하나만 있게 해줘.
4. 답을 선택하면 바로 정답 여부와 2~3문장의 쉬운 해설을 보여줘.
5. 틀렸을 때도 점수만 깎지 말고 기억하기 쉬운 힌트나 관련 사실을 알려줘.
6. 상단에 현재 문제 번호, 진행 막대와 점수를 표시해줘.
7. 모든 문제를 풀면 총점과 결과에 맞는 칭호를 보여줘.
   - 100점: 문화 탐험 마스터
   - 60~80점: 멋진 문화 탐험가
   - 0~40점: 다시 떠나는 탐험가
8. “다시 도전하기” 버튼을 누르면 점수와 문제가 처음으로 돌아가게 해줘.
9. 정답과 해설은 정부·박물관·유네스코·공식 관광기관처럼 신뢰할 수 있는 자료를 확인해 작성해줘.
10. 사실 여부가 불확실하거나 논쟁적인 문제는 내지 말고, 다른 나라 문화를 섞지 마.
11. 디자인은 [국가 이름]의 국기 색을 활용하되 정답 버튼과 오답 버튼이 명확히 구별되게 해줘.
12. HTML, CSS, JavaScript가 한 Canvas 안에서 작동하고 모바일에서도 버튼이 누르기 쉽게 해줘.
첫 번째 수정 미션“문제 순서와 보기 순서가 다시 도전할 때마다 무작위로 바뀌게 해줘.”

역사문화유산 여행 네 컷

너는 개인정보를 안전하게 처리하는 웹앱 개발자야.

[국가 이름]의 역사문화유산을 배경으로 사진을 찍는 “[국가 이름] 문화유산 여행 네 컷” 웹페이지를 만들어줘.

요구사항:
1. 그 나라를 대표하는 실제 역사문화유산 4곳을 조사해 배경 선택 메뉴로 만들어줘.
   - 서로 다른 시대나 지역의 문화유산을 골고루 선택해줘.
   - 유네스코 세계유산, 정부 문화유산 기관 또는 공식 박물관 자료를 우선 확인해줘.
   - 배경 이름과 국가·도시 또는 지역을 함께 표시해줘.
   - 다른 나라의 건축물이나 상징물을 섞지 마.
2. 사용자가 카메라 켜기 버튼을 누른 뒤에만 카메라 권한을 요청해줘.
3. 학생이 교실, 복도, 도서관 또는 방에서 촬영할 수 있으므로 인물 분할 기능을 사용해 실제 촬영 장소의 배경을 제거하고 사람만 선택한 문화유산 배경 위에 보여줘.
4. 촬영 버튼을 누를 때마다 네 컷 칸에 사진을 한 장씩 표시해줘.
5. 촬영한 이미지에도 인물과 선택한 배경이 함께 합성되게 해줘.
6. 사진은 서버로 전송하거나 자동 저장하지 말고 현재 화면에서만 보여줘.
7. 카메라를 끄거나 네 컷을 비우는 버튼을 넣어줘.
8. 인물 분할 기능을 불러오지 못하면 이유와 해결 방법을 화면에 알려줘.
9. 각 문화유산 배경 아래에 이름, 위치, 한 문장 설명과 이미지 출처를 표시해줘.
10. 인물과 촬영 장소 배경의 색이 비슷해 분리가 어려울 수 있으니, 밝은 곳에서 벽이나 사물과 조금 떨어져 촬영하라는 안내를 보여줘.
11. 인물 분할 경계가 불안정할 때 사용할 수 있는 “분할 강도” 또는 “경계 부드럽게” 조절 기능을 넣어줘.

주의: 카메라는 HTTPS 환경에서만 작동하며 사진을 서버에 전송하지 않는다는 안내를 넣어줘.
첫 번째 수정 미션“각 촬영 전에 3·2·1 카운트다운이 나오도록 추가해줘.”

문화 체험 방명록

너는 중학생 문화 체험 행사에 사용할 방명록 웹페이지 개발자야.

[대한민국 문화 체험] 후기를 남기는 안전하고 밝은 웹페이지를 만들어줘.

요구사항:
1. 닉네임, 가장 기억에 남은 문화, 별점, 80자 이내 한 줄 후기를 입력하게 해줘.
2. 이름, 전화번호, 학교, 주소 등 개인정보를 적지 말라는 안내를 보여줘.
3. 등록한 후기는 최신 글이 위에 보이게 해줘.
4. 새로고침 후에도 같은 기기에서 후기가 보이도록 localStorage를 사용해줘.
5. 후기는 최대 20개까지만 보관해줘.
6. 사용자가 입력한 HTML이나 스크립트가 실행되지 않도록 안전하게 처리해줘.
7. 삭제 버튼을 누르면 확인 후 해당 후기만 삭제되게 해줘.
8. 전체 후기 수와 평균 별점을 상단에 보여줘.
